# Contributing

This repository is a compact, reproducible analytics workbench. Changes should preserve three properties:

1. **Claims are traceable.** Any numerical claim in `README.md` should either be regenerated by the current reference workflow or explicitly labelled as a preserved planning snapshot.
2. **Certified metrics never consume rejected rows.** New quality checks should retain rejected-row evidence while keeping it out of Gold metrics.
3. **Decision gates are non-compensatory.** A commercial upside must not numerically cancel a declared customer-safety guardrail.

## Development

```bash
python -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
pip install -e .
pytest -q
python scripts/run_workbench.py --output-dir build/reference
python scripts/validate_build.py build/reference
```

Please add or update tests for changes to metric definitions, certification logic, forecast gates or experiment constraints.
