# Preserved reference and planning snapshots

The CSV files in this directory are retained for compact comparison with the broader pre-v0.23 analysis.

They are **not all generated by the current compact `scripts/run_workbench.py` pipeline**.

- `reference_summary.csv` records selected historical reference claims together with their interpretation limits.
- `risk_aware_design.csv` records the preserved unequal-randomisation planning comparison.

For evidence generated by the current v0.23 workflow, run:

```bash
make reference
make validate
```

or download the `reference-evidence` artifact from a successful GitHub Actions run. The generated artifact contains its own `MANIFEST.json` with SHA-256 hashes.

See `docs/REPRODUCIBILITY.md` for the provenance rule used throughout the repository.
